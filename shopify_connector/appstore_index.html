Shopify Connector for Odoo 19

Connect your Shopify store with Odoo — products, orders, inventory, returns and accounting.
Built for European business. GDPR compliant. Available in Dutch and English.

Key Features

📦 Product Sync

Sync products and variants from Odoo to Shopify automatically. Import existing Shopify products into Odoo in one click — including inventory levels.

🏭 Inventory Sync

Real-time inventory synchronization between Odoo and Shopify. Supports multiple warehouse locations mapped to Shopify locations.

🛒 Order Import

Automatically import Shopify orders into Odoo. Creates customers, order lines, shipping costs and discounts automatically. Webhook-based real-time updates.

🚚 Fulfillment & Tracking

Send tracking codes back to Shopify automatically when a delivery is validated in Odoo. Supports carrier mapping for all shipping methods.

↩️ Returns & Refunds

Process returns in two ways: via Shopify self-service portal or directly from Odoo. Automatic credit notes, refund mutations and inventory correction.

🧾 Accounting

Automatic invoicing, payment registration on intermediary account, and credit notes. European VAT support. Fully compatible with Odoo Accounting.

Up and Running in Minutes

  1. Install the module from the Odoo App Store
  2. Connect your Shopify store via OAuth — no API keys to copy
  3. Map Shopify locations to Odoo warehouses
  4. Import existing products from Shopify (optional)
  5. Done — orders, inventory, fulfillment and returns are now automated
